# real-asset-pipeline — 실물 자산 반영 규약

원칙: **실물 사진이 스톡·AI 이미지보다 항상 낫다. 단, 확인된 것만 쓰고 추측으로 채우지 않는다**("마땅한 게 없으면 안 넣는다"가 기본값).

## 1. 보존
첨부·클라우드 파일은 즉시 안정 경로로 복사(임시 경로는 만료). 개인정보성 파일명(기기 UUID·IMG_xxxx)은 반영 시 의미 있는 이름으로 변경.

## 2. 판독·선별
- 후보 다수면 콘택트 시트 또는 썸네일 개별 판독. HEIC→sips, 엑셀 임베드→`unzip -j "xl/media/*"`(특정 사진 지목은 색 평균 스캔+셀 앵커 파싱, 최종은 육안).
- 영상 프레임: 정적 구성 1fps/타이밍 6fps+, 최선명 프레임은 엣지 평균 랭킹+육안. 영상 정체를 전제하지 말 것.
- 용도 적합성 판정(광고 전단 사진은 현장 씬에 부적합 등) — 부적합만 있으면 "무대체 삭제" 제안.

## 3. 변환·규격
같은 섹션 기존 자산의 px·포맷을 먼저 조사해 그 규격대로. 저해상 자산은 표시 크기 대비 판단(썸네일 ≤2x면 수용).

## 4. 버저닝 (하드 룰)
**동일 파일명 내용 교체 금지** — Next/Vercel 이미지 캐시가 옛 변형을 TTL 만료 후에도 1회 서빙(stale-while-revalidate, ETag로 실증). 교체는 `-v2` 파일명+참조 전수 갱신+구 파일 삭제(404 확인).

## 5. 게재 게이트
새 캡션·설명은 확인된 사실 범위 내(카피 린트 통과). 반영 후 실측: 서빙 해시=원본 해시, 구 참조 0, 레터박싱 %(3:1+ 초광폭은 미디어 박스 aspect 별도), 모바일 오버플로. 출처(경로·URL)를 작업 로그에 기록.

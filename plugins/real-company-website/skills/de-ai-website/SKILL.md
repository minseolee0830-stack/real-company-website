# de-ai-website — AI스러움 판별·교정 절차

AI 생성 사이트는 "통계적 평균"으로 수렴해서 서로 닮는다. 이 스킬은 **판별 → 교정 → 재발 방지 게이트** 3단계로 그 수렴을 깬다. 감상("더 세련되게")이 아니라 **판별 가능한 신호와 실행 가능한 교정**만 다룬다.

## 1단계 — 판별: AI스러움 신호 체크리스트

### 시각 신호 (렌더 실측으로 검사)
- [ ] **기본 폰트 방치**: Inter/Roboto/Arial을 무선택으로 사용 (브랜드 선택 흔적 없음)
- [ ] **보라·인디고 그라디언트**: Tailwind `bg-indigo-500` 계열 히어로/CTA (#6366F1→#8B5CF6)
- [ ] **아이콘 3카드 그리드**: 아이콘+제목+두 줄 설명 카드 3개 나열 — AI 랜딩의 시그니처
- [ ] **전 요소 동일 라운딩·패딩**: 모든 박스가 같은 radius(예: 16px)와 그림자(0.1 투명도)
- [ ] **스톡/AI 일러스트**: "노트북 앞의 다양한 사람들" 사진, 과하게 매끈한 일러스트
- [ ] **장식용 페이드인**: 의미 없는 균일 fade-in, hover 피드백 부재
- [ ] **이모지 아이콘**: 실제 기업 사이트는 UI에 이모지를 거의 쓰지 않는다

### 카피 신호 (innerText 전수 스캔)
- [ ] **자기 서술 부제**: 화면이 스스로를 설명("~를 한눈에 확인합니다", "~를 먼저 둡니다", "~를 모았습니다") — 제거 대상 1순위
- [ ] **제목 재탕**: eyebrow(킥커)=h1, 부제=제목 되풀이, 같은 문구가 한 화면에 2회 이상
- [ ] **헤징·필러**: "~할 수 있습니다"만 반복, "중요한 것은", 정보 없는 연결문
- [ ] **어휘 틱**: 같은 단어가 파일/페이지에 수십 회("기준", "확인합니다" 등) — 카운트로 검출
- [ ] **균일 어미**: 같은 종결어미 연속(파일당 동일 어미 4회 이상이면 신호)
- [ ] **뜬구름 헤드라인**: "미래를 만듭니다"류 — 어느 회사에 붙여도 말이 되면 실격
- [ ] **내부 용어 노출**: 제작 과정 용어(관리자/CMS/검수/승인/화면 구성 단어)가 방문자 화면에
- [ ] **번역투**: "왜 ~인지는 ~로 확인합니다" 같은 영문 직역 구조

### 구성 신호
- [ ] **모든 페이지 같은 뼈대**: 히어로→3카드→CTA 반복, 페이지 간 밀도 차 없음
- [ ] **신뢰 신호 부재**: (한국 기업 관습) footer 법정 표기(상호·대표·주소·연락처), 이용약관·개인정보처리방침, 회사소개(인사말·연혁), 실제 공지 — 없거나 placeholder면 "가짜 회사" 인상
- [ ] **빈 상태 노출**: "준비 중", 공지 0건, 더미 텍스트

## 2단계 — 교정 절차 (순서 고정)

1. **사실 수집이 먼저**: 오너/실무자만 아는 사실(제품·규격·사진·연혁·문구)을 확보하거나 질문지로 요청. **없는 사실을 지어내지 않는다 — 특이성은 진짜 사실에서만 나온다.** 오너가 직접 쓴 문장은 원문 그대로가 최고의 카피다(맞춤법 교정도 확인 후에).
2. **카피 교정**:
   - 자기 서술 부제 전부 삭제. 유지 기준은 단 하나: **"이 부제가 새로운 사실(수치·조건·방법)을 주는가?"** 아니면 제목만 남긴다.
   - 헤드라인 = 구체 사실("하루 4톤", "화·수·목·금 수령")로. "CEO가 실제로 이렇게 말하겠는가?" 테스트.
   - 어휘 틱은 카운트 → 문형 자체를 바꿔 해소(동의어 치환만 하면 새 틱이 생긴다 — 실증됨). 같은 파일 동일 어미 ≤3.
   - 독자를 한 명으로 특정(예: "전국 식당 사장님")하고 모든 문장을 그 사람에게 말하듯.
3. **시각 교정**:
   - 폰트 2단 체계(헤드라인+본문)를 **선택의 근거와 함께** 고정. 금지 목록 명시("Inter/Roboto 금지").
   - 색은 팔레트가 아니라 **기능 규칙**: 액션색 1종(CTA·링크 전용), 주색은 2단계(쨍한 톤=CTA, 톤다운=뱃지·라벨), 유채색 남발 금지. 시맨틱 토큰명(--color-action, --primary-soft).
   - 사진은 실물만: 실제 제품·실제 작업장·실제 팀. 스톡·AI 일러스트 전면 교체. 확인 안 된 사진은 게재 금지.
   - 카드 위계 분화: 콘텐츠/미디어 라운딩을 구분, 틴트 2종 교차(진한 색칠 대신 옅은 배경 교차)로 리듬.
   - 모션 1종 원칙: 진입 리빌 하나로 통일, 장식 애니메이션 삭제, 상태 변화·주의 유도에만 모션.
4. **구성 교정**:
   - 실존 기업 1~2곳을 벤치마크로 지정(같은 업종+디자인 상급)하고 **문법을 추출해 이식**(/benchmark-design 스킬). "예쁘게"가 아니라 실물 참조로 지시.
   - 한국 기업 관습 충족: footer 법정 표기 한 줄, 이용약관·개인정보처리방침 실문서(사이트 실동작 기준으로 정직하게), 공지 최소 1건 실게시, 회사소개는 나열이 아니라 흐름(배경→성장→방향).
   - 페이지마다 밀도·톤 차이를 의도적으로(전부 같은 템플릿이면 신호).

## 3단계 — 게이트 (재발 방지)
- 금지어/금지 문형 목록을 프로젝트 문서에 명문화하고, 커밋 전 자동 검사(카피 린트)에 연결.
- 교정 후 **실브라우저 실측**(/visual-qa-prod): 제목 재탕 0, 자기 서술 0, 어미 카운트, 신뢰 신호 렌더.
- 최종 판정 질문 4개: ①첫 3초에 무슨 회사인지 아는가 ②사업이 이해되는가 ③이 문장을 대표가 실제로 말하겠는가 ④이 페이지를 다른 회사에 그대로 줘도 말이 되는가(되면 실격).
